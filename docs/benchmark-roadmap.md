# KCU website: benchmark roadmap (ASU and SMU)

The Vice Chancellor's feedback was that the website concept is good, and that we should benchmark it against
**Arizona State University** (asu.edu) and **Singapore Management University** (smu.edu.sg). This list comes from
reviewing both homepages section by section and measuring their design (fonts, sizes, colours, buttons, cards,
spacing) against ours, in November 2026.

**How to use this list:** change `[ ]` to `[x]` when an item is done and checked on the live site. Add the date
and initials in the Done column. Items marked **KCU** need a decision or content from the University. Items marked
**Dev** can be built by the web team.

Priority: **P1** = do first (biggest impact), **P2** = next, **P3** = later.
